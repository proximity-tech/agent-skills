# Agent guidance

- Keep reusable skills under `skills/<skill-name>/SKILL.md` with `name` and `description` in YAML frontmatter.
- Keep skill instructions portable across developers and avoid hard-coding personal identities, local paths, Jira sites, or credentials.
- Preserve the user's chosen scope and use read-only sources for reports unless the user authorizes another action.
- Update the README when installation or invocation instructions change. Do not commit generated reports or personal data.
